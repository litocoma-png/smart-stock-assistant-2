Offline and device limitation: this prototype saves data in the browser on the device. It does not automatically sync between phone and computer. Back up and restore manually to move data between devices. For dependable camera scanning, open it from a secure website (HTTPS) or localhost; manual barcode entry remains available.

How to install

  1. Download and unzip the app package on your Windows computer.
  2. Open index.html in Chrome or Edge to test it.
  3. On Android, copy the file to your phone and open it in a browser if supported. For best installation and camera support, host the folder on an HTTPS static host or local web server, then open the URL in Chrome.
  4. In Chrome on Android, use the browser menu and choose Add to Home screen or Install app when offered.
  5. Use Backup & setup to export a backup before changing browser, clearing storage, or moving devices.

This first version is a local web app prototype, not a Play Store APK. Do not use it as your only accounting record until you have tested backups, prices, and sales on sample data.
